# Agua turbia en Guadalajara

Página informativa que explica, con ilustraciones y fuentes citadas, la crisis de calidad del agua en la Zona Metropolitana de Guadalajara (2026): de dónde viene el agua, dónde se contamina, el plan del gobierno, el debate del acueducto sustituto Chapala–Guadalajara y las alternativas.

- Sitio estático: un solo `index.html`, sin dependencias ni build.
- Ilustraciones en SVG inline, con modo claro y oscuro.
- Fuentes numeradas al final de la página; cada dato enlaza a su fuente.

Datos actualizados al 20 de octubre de 2026.

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Despliegue

Desplegado en Vercel como sitio estático (sin framework ni comando de build).
